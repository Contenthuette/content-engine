# Hook-Bibliothek (die ersten 1,5 s)

Pflicht für jeden Hook (STYLE_SYSTEM §1.1): Frame 0 voll · erste Veränderung ≤ 0,2 s · ≥ 3 Ereignisse bis 1,5 s ·
Sound-Treffer auf Frame 0–3 · gesprochener Hook ≤ 2,5 s. Formel nicht wie in den letzten 3 Reels der Marke.
Neue Formeln aus Referenzen hier ergänzen (ID fortlaufend, mit Referenz-Link).

| ID | Name | So läuft es ab | Passt zu |
|---|---|---|---|
| H01 | Slam-Wort | Stärkstes Bild des Themas füllt das Bild, 1 Schlüsselwort schlägt riesig ein (Scale 1.4→1, Blur → 0, Bass-Impact, Kamera-Punch), Avatar fliegt rein | Warnungen, Hot Takes |
| H02 | Ergebnis zuerst | Das fertige Wow-Ergebnis (Output, Zahl, Vorher/Nachher) läuft ab Frame 0, dann Rückspul-Wisch → „so geht's“ | Tutorials, Tools |
| H03 | Crash-Zoom | Crash-Zoom auf Avatar-Gesicht (0–6 Frames), Freeze, Hook-Satz als 2–3 große Wörter daneben | Persönliche Aussagen |
| H04 | Pattern-Interrupt | Etwas Unerwartetes passiert physisch (Bild kippt/fällt, Objekt zerbricht, Bild faltet sich) und gibt das Thema frei | Alles, gut als Re-Hook |
| H05 | Zahl-Explosion | Riesige Zahl zählt in 0,8 s hoch, Ziffern-Rollen, Partikel, Einheit landet mit Pop | Daten, Geld, Reichweite |
| H06 | Split-Reveal | Bild reißt/teilt sich in der Mitte, dahinter das eigentliche Thema; Teile fliegen mit Motion Blur raus | Enthüllungen |
| H07 | Objekt in die Kamera | Leitidee-Objekt (3D/Freisteller/Logo) fliegt aus der Tiefe in die Kamera, Landung mit Schockwelle | Produkte, Tools |

| H09 | Screen-Crash | Echte Bildschirmaufnahme, Crash-Zoom auf den entscheidenden Bereich, Cursor klickt, Highlight-Ring | Software-Demos |
